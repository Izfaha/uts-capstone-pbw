# Capstone Project - Pemrogramman Berbasis Web

Installation Runner :
- Jalankan `docker compose up --build`
- buka browser lalu ketik :
    - `localhost:8085/login.php`
    - `localhost:8085/koneksi.php`

Strictly needed :

| Files/Dirs |                           Usage                            |
| :--------- | :--------------------------------------------------------: |
| img/       |                 Untuk menaruh semua gambar                 |
| index.html |                         file HTML                          |
| style.css  | file css untuk custom tambahan dan meng-overrite bootstrap |
| script.js  |                      file JavaScript                       |
